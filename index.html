🛡️ Day 11 — Fiarovana sy fitsapana

🔐

Fiarovana kaonty

Rehefa ampidirina ny backend: tenimiafina hashée (Argon2id na bcrypt), fanamarinana mailaka, famerana andrana fidirana, session azo antoka ary MFA raha azo atao.

🧱

Fiarovana angona

HTTPS, RLS amin’ny Supabase, fahazoan-dalana faran’izay kely, fanamarinana input amin’ny serveur, fiarovana XSS/CSRF ary tsiambaratelo tsy apetraka ao amin’ny kaody public.

🧑‍⚖️

Fiarovana ny mpampiasa

Politika momba ny tsiambaratelo, fitsipika fampiasana, tatitra sy fanakanana kaonty, fanaraha-maso votoaty, ary fomba fangatahana famafana angona.

🧪

Fitsapana mandeha ho azy

Jereo ny rohy, singa HTML fototra, script, fampisehoana finday ary fitahirizana eo an-toerana. Ity fitsapana eto ambany ity dia fanamarinana fototra ihany.

Mbola tsy natao ny fitsapana.

🚀 Day 12 — Fanomanana famoahana ampahibemaso

Safidy fotodrafitrasa nifanarahana: GitHub hitahirizana kaody, Cloudflare Pages ho hosting, Supabase ho database/authentication/Realtime, ary HTTPS.

  1. GitHub: mamorona repository G, mampiditra ny rakitra farany, ary mitazona backup.
  2. Supabase: mamorona project, manorina schema sy Row Level Security (RLS), Auth, policies ary fitahirizana sary; aza apetraka amin’ny client ny service-role key.
  3. Fanomanana kaody: esorina ny angona santionany, ampifandraisina amin’ny API azo antoka ny social, Jobs, Academy ary Marketplace; ampiana moderation sy fitsipika tsiambaratelo.
  4. Cloudflare Pages: ampifandraisina amin’ny repository GitHub, faritana ny build settings, ary alefa aloha amin’ny preview URL hanaovana fitsapana.
  5. Fiarovana sy fanamarinana: HTTPS, security headers, environment variables, backup, fitsapana finday sy navigateur, ary fanaraha-maso ny fahadisoana.
  6. Famoahana: rehefa vita ireo rehetra ireo vao ampifandraisina ny domaine public ary avoaka amin’ny olona.
⚠️ Zava-dehibe: vita eto ny fanomanana sy ny checklist Day 11–12, fa tsy mbola navoaka amin’ny Internet ny G. Tsy mbola manana fidirana amin’ny kaontinao GitHub, Cloudflare na Supabase aho, ary tsy mbola mifandray amin’ny backend ny prototype. Tsy tokony hatao public raha tsy vita ny backend, fiarovana, fitsapana ary fanamarinana ara-dalàna.

Dingana manaraka ara-teknika: mamorona repository sy Supabase project, avy eo mampifandray ny rakitra. Mila fanatanterahana ao amin’ny kaontinao ireo dingana ireo.
