Tsy mbola public ny G. Vita ny prototypes HTML sy ny torolalana, saingy tsy mbola voamarina fa mifandray amin'ny backend, tsy mbola voasedra ny fiarovana manontolo, ary tsy mbola misy adiresy public navoaka tamin'ny Cloudflare Pages.

🧭 Fomba famoahana amin'ny Cloudflare Pages

Manomàna ny GitHub repository
Hamarino fa ao amin'ny root an'ny heryfaly003-cloud/G ny rakitra ilaina. Ampidiro ny dikan-teny farany amin'ny Day 4–12, ary amboary ny index.html ho pejy fandraisana mampifandray azy ireo.
Mamoròna tetikasa Cloudflare Pages
Midira amin'ny kaontinao Cloudflare, safidio Workers & Pages → Create → Pages → Connect to Git. Safidio ny repository G.
Safidio ny build settings
Ho an'ny HTML/CSS/JavaScript tsotra: Build command avela foana raha tsy misy build step; Build output directory apetraho amin'ny / na root directory araka ny asehon'ny dashboard.
Deploy preview
Atombohy amin'ny preview deployment. Jereo ny rohy rehetra, ny endrika amin'ny finday, ny console errors ary ny pejy tsy hita.
Ampifandraiso ny backend rehefa vonona
Amboary ny Supabase Auth, database, Storage ary RLS policies. Aza apetraka ao amin'ny frontend ny service-role key na secrets.
Fanamarinana fiarovana sy famoahana
Hamarino HTTPS, permissions, privacy policy, terms, backup/restore, report/block/moderation ary ny fomba famafana kaonty. Rehefa vita ihany vao alefa ho public.
Domain manokana (raha ilaina)
Afaka ampifandraisina aorian'izay ny domain-nao amin'ny Cloudflare Pages, ary hamarino ny DNS sy HTTPS.
